# How to Be Cool

Hayden's searchable guide to places to eat, things to do, gifts, wishes, outfits and lists to share.

**Live guide:** https://claude.ai/artifact/JZUf8eS61hLWZzg8sA5CSQ (private to you)

Everything you add on the page (items, categories, outfits, lists) is saved in the guide itself on claude.ai, not in this folder.

## What's in this folder

- `guide.html`: the page's source. Claude edits this and republishes it to the link above.
- `share/make_list_page.py`: builds the separate page for a list you share with someone.
- `data/`: the notes Claude imported (your original list and the NYC / Brooklyn notes).

## Picking up later

Open this session (or start one in this folder) and say what you want, for example:

- "Publish my list 'Gift ideas for Milo'"
- "Here are more notes to add"
- "Add photos to the feed"
